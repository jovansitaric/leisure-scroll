LeisureScroll

A high-performance hybrid scroll-reveal library. Uses native CSS scroll timelines when the browser supports them, with an instant IntersectionObserver fallback.

CSS Custom Properties Advanced Styling

Fine-tune the reveal with --ls-scale and --ls-easing (both paths), --ls-duration and --ls-delay (Observer fallback), or --ls-range-start / --ls-range-end (native scroll timeline).

Custom Duration & Delay fallback only

Slowed down with --ls-duration: 1.2s and --ls-delay: 300ms. On native scroll timelines, progress follows the scroll position instead of the clock.

Custom Scroll Range native only

The reveal completes exactly as the element finishes entering the viewport, set with --ls-range-start and --ls-range-end.

Custom Zoom Scale

Initial scale overridden using --ls-scale: 0.4.

Custom Easing Curve

Applies an elastic curve via --ls-easing.

Repeat Mode Controls Once Parameter

Both paths now repeat by default — elements reset and re-animate every time they scroll in and out of view (native mirrors automatically; the fallback re-triggers via IntersectionObserver). Set data-ls-once="true" for the classic single-shot AOS behavior; it only affects the Observer fallback.

Once: False (Default)

Resets on exit and re-triggers on every scroll past (Observer fallback).

Once: True (Single-shot)

Animates once on first entry and holds the final state (Observer fallback).
